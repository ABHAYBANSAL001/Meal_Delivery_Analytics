# MealX – Meal Delivery Analytics

## Overview
End-to-end analytics project analyzing meal delivery performance using SQL and Python.

## Project Structure
- data/raw: original datasets
- data/cleaned: processed data
- sql: data cleaning and analysis queries
- scripts: Python data pipeline
- notebooks: exploratory analysis
- docs: documentation and assets

## Pipeline
Raw Data ? SQL/Python Cleaning ? Analysis ? Insights

## Key Insights
- Order trends by time and region
- Impact of discounts on revenue
- Delivery performance metrics

## How to Run
1. Place dataset in data/raw
2. Run scripts/load_and_clean.py
3. Open notebooks/analysis.ipynb
